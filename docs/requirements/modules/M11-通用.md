## 1. 模块概述

通用模块提供 OMS 全平台共用的横切能力，本身不承载具体业务功能，但被各业务模块普遍依赖。它统一解决多语言呈现、后台任务承载、操作日志上报与平台品牌展示四类共性问题，使各子模块无需各自重复建设。模块向下为 M08 操作日志管理提供一致的上报能力，并为 M09 运行日志管理、M10 备份恢复提供任务承载能力。本模块不依赖其他 OMS 模块，是全平台的基础支撑层。

| 项 | 内容 |
| --- | --- |
| 模块定位 | 提供全平台共用的多语言、任务承载、操作日志上报与品牌展示等横切能力 |
| 上游依赖 | 无 |
| 下游影响 | M08 操作日志管理（依赖本模块的上报能力形成统一日志）；M09 运行日志管理与 M10 备份恢复（依赖本模块的任务中心承载其任务） |
| 关键外部系统 | 无 |

### 3.1 FR-COM-001 国际化

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-COM-001 | V1.0 |

**② 需求描述**

作为业务运维人员，我希望界面文案、提示信息与操作日志展示支持多语言切换，并且时间按我设置的时区呈现，以便不同语言背景的人员都能无障碍地使用系统与查阅记录。

**③ 前置条件与触发方式**

- 前置条件：系统已配置默认语言与可选语言清单；操作日志管理中已有可展示的记录；用户已登录
- 触发方式：导航栏的语言与时区切换入口；用户登录时按个人偏好自动呈现；系统默认语言由配置变更触发

**④ 主流程**

1. 用户登录后，系统按用户个人偏好或系统默认语言呈现界面
2. 用户在语言切换入口选择目标语言
3. 系统即时切换界面文案、提示信息与操作日志的展示语言
4. 用户设置时区后，系统按该时区呈现各处时间信息
5. 系统保存用户的语言与时区偏好，下次登录自动生效

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 界面文案、提示信息与操作日志展示 | 均支持多语言，不得固定为单一语言 | 无 |
| 默认语言 | 由系统管理员配置；新用户及未设置偏好的用户按默认语言呈现 | 无 |
| 用户切换语言 | 切换后当前页面立即生效，无需重新登录 | 无 |
| 用户切换时区 | 时间信息按用户设置的时区呈现，同一时间点在不同时区下指向同一时刻 | 无 |
| 用户未设置语言或时区偏好 | 按系统默认语言与默认时区呈现 | 无 |
| 缺少对应语言的文案 | 回退为默认语言展示，不得出现空白或占位内容 | 无 |

**待确认**

OI-G-005（已登记于主文档附录 B，本分册不重复跟踪）：首发需要支持哪些语言、默认语言与默认时区如何确定？

### 3.2 FR-COM-002 任务中心（日志收集、备份任务）

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-COM-002 | V1.0 |

**② 需求描述**

作为业务运维人员，我希望在一个统一的任务列表中查看日志收集、备份等后台任务的进度、状态与失败原因，并能取消进行中的任务，以便集中掌控后台任务运行情况。

**③ 前置条件与触发方式**

- 前置条件：操作者具备任务查看权限；已有子模块提交或正在执行的任务；操作者已登录
- 触发方式：任务中心页面入口；事件（子模块发起任务后自动出现在任务列表中）

**④ 主流程**

1. 操作者进入任务中心，系统展示任务列表并支持按任务类型、状态与时间范围筛选
2. 操作者选择任一任务查看详情，包括发起模块、任务类型、进度、状态与执行结果
3. 任务失败时，系统展示失败原因
4. 操作者对进行中的任务发起取消
5. 系统按发起子模块的规则处理取消请求并反馈结果
6. 操作者按条件查询历史任务，并按需清理已无保留价值的历史任务记录

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 任务承载范围 | 统一承载日志收集任务、备份任务及其他子模块提交的后台任务，子模块业务规则仍由其自身定义 | FR-BAK-001 |
| 任务状态展示 | 覆盖排队中、执行中、成功、失败、已取消 | 无 |
| 任务正在执行 | 进度持续刷新并展示可获得的剩余时间信息 | 无 |
| 取消进行中的任务 | 按发起子模块的规则执行取消，取消结果与原因在任务列表中体现 | 无 |
| 任务执行失败 | 展示失败原因，并由发起子模块按其规则触发告警或重试 | FR-BAK-002 |
| 历史任务查询与清理 | 支持按条件查询历史任务；清理仅移除任务记录，不影响任务产生的业务数据与备份文件 | FR-BAK-003 |
| 操作者无任务操作权限 | 拒绝查看或取消并提示 | FR-PERM-001 |

### 3.3 FR-COM-003 子模块操作日志上报

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-COM-003 | V1.0 |

**② 需求描述**

作为审计管理员，我希望各子模块的关键操作都以一致的内容与方式被统一记录，以便操作行为完整可查、口径统一，且上报异常不会影响业务操作本身。

**③ 前置条件与触发方式**

- 前置条件：各子模块已接入统一上报能力；操作日志管理可用；上报通道可用
- 触发方式：事件（子模块发生需留痕的操作时自动触发）

**④ 主流程**

1. 子模块中发生需留痕的操作
2. 子模块按统一约定向本模块提交操作日志内容
3. 系统校验上报内容的完整性与合规性
4. 系统将操作日志转交操作日志管理统一存储与展示
5. 系统向上报方反馈处理结果

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 上报内容一致性 | 各子模块上报的操作日志内容项保持一致，不因模块差异缺失关键项 | 无 |
| 上报失败 | 不阻断、不回滚子模块的主业务流程，仅记录失败并按策略重试 | 无 |
| 上报动作对业务无侵入 | 子模块无需改变自身业务流程即可完成上报 | 无 |
| 上报内容不完整或不合规 | 拒绝接收并向上报方反馈原因 | 无 |
| 上报通道不可用 | 暂存待上报内容，通道恢复后补报；超出暂存时限时告警；通道恢复且补报成功后主动向 M17 告警管理上报消除信息 | FR-ALM-005 |
| 上报成功后的操作日志 | 按操作日志管理要求留存且不可被修改 | 无 |
| 操作者无操作日志查看权限 | 拒绝查看并提示 | FR-PERM-001 |

**待确认**

### 3.4 FR-COM-004 Logo 修改

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-COM-004 | V1.0 |

**② 需求描述**

作为系统管理员，我希望替换平台在登录页与导航栏展示的 Logo，并能恢复为默认 Logo，以便平台外观与本单位品牌形象保持一致。

**③ 前置条件与触发方式**

- 前置条件：操作者具备品牌配置权限；已准备符合要求的 Logo 图片；系统当前 Logo 配置可读
- 触发方式：品牌设置页面的 Logo 替换入口

**④ 主流程**

1. 操作者进入品牌设置页面，查看当前 Logo 与默认 Logo
2. 操作者上传新的 Logo 图片
3. 系统校验图片格式与大小是否符合要求
4. 系统保存新 Logo，并立即在登录页与导航栏生效
5. 操作者在需要时执行恢复默认，系统还原为默认 Logo

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 图片格式 | 仅接受常见图片格式，格式不符时拒绝上传并说明原因 | 无 |
| 图片大小 | 超过大小上限时拒绝上传并提示，要求操作者调整后重试 | 无 |
| 替换后生效时机 | 立即生效，用户刷新页面或重新登录后看到新 Logo，无需重启系统 | 无 |
| 恢复默认 | 支持一键还原默认 Logo，恢复后立即生效 | 无 |
| 图片内容不合法或无法解析 | 拒绝保存并保留原 Logo 不变 | 无 |
| 替换与恢复默认动作留痕 | 记录操作者、时间与动作结果 | FR-COM-003 |
| 操作者无品牌配置权限 | 拒绝替换或恢复并提示 | FR-PERM-001 |
