## 1. 模块概述

OMS 在本分册中同时承担「身份提供方」「身份接入方」与「SSO 代理」三重角色：作为代理时，OMS 对下游业务系统是统一认证服务（SSO Server），对上游统一认证服务是接入方（SSO Client），把「下游业务系统 → OMS → 上游统一认证服务」串成一条认证链路，用户在链路上的认证与登出由此级联完成。具体来说：SSO Server（M05）面向以 OMS 客户端身份接入的上层业务系统，在多个客户端之间共享 OMS 的登录态，使用户一次登录即可免重复认证地访问各业务系统，并在登出时统一撤销各客户端的登录态。SSO Client（M06）用于 OMS 自身对接第三方认证系统，使 OMS 可作为被认证方接入外部身份源，并把外部身份关联到 OMS 本地的外部账号。**上游统一认证服务只提供身份信息，不提供角色或权限信息**；外部账号的权限来源是其在 OMS 导入时指定的用户组（见 FR-SSOC-003），OMS 在登录时不做任何角色映射。此外，本分册负责**外部账号的导入**：使用上游统一认证服务登录的用户，必须先通过导入在 OMS 中建立**外部账号**并指定其所属用户组，OMS 不在本地为其保存认证凭据；在 OMS 本地认证的**本地账号**则由 M01 账户管理在页面上创建，两者不得混用。上述能力共同解决多系统之间身份分散、重复登录、登出后登录态残留等问题。本模块的登录态建立与失效依赖 M01 账户管理提供的本地账户与 M02 登录管理提供的本地会话；跨客户端的登出传播（SLO）由本分册自行承担，M02 只负责 OMS 本地会话登出。本模块直接影响所有以 SSO 客户端方式接入 OMS 的上层业务系统。

| 项 | 内容 |
| --- | --- |
| 模块定位 | OMS 作为统一身份提供方（对下游）、身份接入方（对上游）与 SSO 代理，提供跨系统的登录态共享、认证链路级联与外部身份接入能力 |
| 上游依赖 | M01 账户管理提供本地账户及账户状态；M02 登录管理提供本地会话建立与会话失效能力；跨客户端登出传播（SLO）由本分册承担；M03 角色管理提供内置角色；M04 资源组与用户组管理提供用户组作为外部角色映射的目标；M15 安全策略管理提供会话策略 |
| 下游影响 | 下游业务系统作为 SSO 客户端接入后，其用户认证与登出均经 OMS 串联上游完成；某一环节的凭据失效会沿链路传播 |
| 关键外部系统 | 上游统一认证服务（OMS 作为其 SSO 客户端接入）；下游业务系统（作为 SSO 客户端接入 OMS） |

### 3.1 SSO Server

#### 3.1.1 FR-SSOS-001 客户端单点登录

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOS-001 | V1.0 |

**② 需求描述**

作为上层业务系统，我希望在其用户尚未持有本系统登录态时由 OMS 校验本地会话并直接建立该客户端的登录态，以便用户一次登录即可在多个已接入的业务系统中免重复认证地访问。

**③ 前置条件与触发方式**

- 前置条件：该上层业务系统已在 OMS 登记为可信的 SSO 客户端且处于启用状态；该客户端登记的重定向地址有效；OMS 本地账户与本地会话能力可用
- 触发方式：事件：上层业务系统的用户尚未持有本系统登录态时发起单点登录请求

**④ 主流程**

1. 上层业务系统在其用户尚未持有本系统登录态时，向 OMS 发起单点登录请求
2. OMS 校验请求来源是否为已登记且启用的 SSO 客户端
3. OMS 校验发起方用户当前在 OMS 的本地会话是否有效
4. 本地会话有效时，OMS 直接为该客户端建立登录态
5. 本地会话不存在或已失效时，OMS 引导用户完成认证：已登记上游统一认证服务时按级联方式重定向上游完成认证，未登记时使用 OMS 本地登录页
6. 登录成功后，OMS 建立该客户端的登录态并继续完成本次单点登录
7. 客户端依据取得的登录态向用户放行原本要访问的业务页面

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 请求来源未登记或已被禁用 | 拒绝本次单点登录请求，并提示联系管理员 | 无 |
| 本地会话已失效 | 引导用户重新认证，认证成功后继续完成本次单点登录 | FR-AUTH-003 |
| 本地会话不存在且已登记上游统一认证服务 | 重定向到上游完成认证，按级联链路建立登录态 | FR-SSOC-002 |
| 对应本地账户已锁定或已停用 | 拒绝为该客户端建立登录态 | FR-ACC-004 |
| 用户不具备该客户端所要求的使用权限 | 拒绝单点登录并提示无访问权限 | FR-PERM-001 |
| 同一用户重复发起单点登录请求 | 复用已建立的客户端登录态，不重复建立 | 无 |
| OMS 登录能力不可用 | 拒绝单点登录并提示稍后重试，不得降级为免认证访问 | 无 |
| OMS 认证能力不可用时的降级策略 | **拒绝登录、会话失效**：已接入的上层业务系统**拒绝放行登录**，且其**既有会话失效**——不允许「允许本地会话续用」的降级路径；OMS 认证恢复后须重新认证（OI-G-004） | OI-G-004 |
| 客户端被禁用后仍发起单点登录 | 拒绝请求并提示该客户端不可用 | FR-SSOS-002 |

**待确认**

#### 3.1.2 FR-SSOS-002 客户端单点登出

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOS-002 | V1.0 |

**② 需求描述**

作为上层业务系统，我希望用户登出时 OMS 撤销本次登录对应的 ticket 并通知所有使用该 ticket 的下游系统执行登出，以便已离开的用户不会在任何业务系统中继续保留可访问的登录凭据。

**③ 前置条件与触发方式**

- 前置条件：目标客户端已登记为可信 SSO 客户端且处于启用状态；用户在该客户端已存在登录态；OMS 本地会话登出能力可用，且本分册的单点登出传播能力可用
- 触发方式：事件：用户在 OMS 或任一已接入客户端发起登出

**④ 主流程**

1. 用户在 OMS 或某个已接入客户端发起登出
2. OMS 确认登出请求对应的用户及其在各客户端上的登录态
3. OMS 撤销本次登录对应的 ticket
4. OMS 通知相关客户端本次登出已生效
5. 客户端清理自身的登录状态并将用户带回登出后的页面
6. OMS 更新在线会话状态，供管理员查看当前在线用户

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 客户端未登记或已被禁用 | 跳过该客户端，不影响其他客户端的登出 | 无 |
| 目标客户端当前不可达 | 标记为待撤销，并在客户端恢复可达后继续完成撤销 | 无 |
| 客户端登录态已失效 | 按登出成功处理，不重复撤销 | 无 |
| 登出请求来自未认证的调用方 | 拒绝该请求 | FR-AUTH-007 |
| 会话策略要求登出后不得继续访问 | 撤销后任何继续使用原登录态的访问均被拒绝 | FR-SEC-003 |
| 客户端未响应登出通知 | 该客户端的登录态仍按 OMS 侧撤销结果失效 | 无 |
| 用户在多个客户端均有登录态 | 撤销本次登录对应的 ticket，并统一通知**所有曾用该 ticket 免密登录的客户端**执行各自的登出逻辑 | 无 |

**待确认**

无

#### 3.1.3 FR-SSOS-003 登录成功重定向

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOS-003 | V1.0 |

**② 需求描述**

作为上层业务系统，我希望用户登录成功后由 OMS 按本系统登记的重定向地址送回业务页面，以便用户直接落到原本要访问的功能，同时避免登录后被带到非受信地址。

**③ 前置条件与触发方式**

- 前置条件：客户端已登记可信重定向地址范围；本次待跳转地址归属于该客户端；本次单点登录已校验通过且客户端登录态已建立
- 触发方式：事件：单点登录校验通过并完成客户端登录态建立

**④ 主流程**

1. OMS 完成用户登录并建立该客户端的登录态
2. OMS 取出本次请求中该客户端希望返回的地址
3. OMS 校验该地址是否属于该客户端已登记的可信范围
4. 校验通过时，OMS 将用户送回该业务页面
5. 业务页面依据客户端登录态展示用户原本要访问的内容

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 未携带希望返回的地址 | 使用该客户端登记的默认页面 | 无 |
| 地址未在该客户端登记 | 拒绝该地址，改为跳转该客户端的默认页面 | 无 |
| 地址不在已登记的可信范围内（疑似开放重定向） | 拒绝跳转，改为跳转客户端默认页面并记录为安全事件 | 无 |
| 地址所属范围与该客户端不一致 | 拒绝跳转 | 无 |
| 地址指向不被允许的跳转目标 | 拒绝跳转并跳转客户端默认页面 | 无 |
| 客户端在跳转前已被禁用 | 不执行跳转，向用户提示该客户端不可用 | FR-SSOS-001 |
| 用户登录成功后客户端登录态建立失败 | 不执行跳转，提示单点登录未完成 | 无 |

**待确认**

无

### 3.2 SSO Client

#### 3.2.1 FR-SSOC-001 对接第三方认证系统

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOC-001 | V1.0 |

**② 需求描述**

作为系统管理员，我希望在 OMS 中登记并启用第三方认证系统，使 OMS 可被第三方认证，以便用户凭外部身份登录 OMS，减少 OMS 本地凭据的重复维护与分散管理。

**③ 前置条件与触发方式**

- 前置条件：已获得第三方认证系统的接入信息并建立可信关系；OMS 中已存在可供关联的本地账户或按策略允许由外部身份关联；OMS 账户策略允许以外部认证方式登录
- 触发方式：页面入口：第三方认证配置页面；事件：用户在 OMS 登录页选择以第三方身份登录

**④ 主流程**

1. 系统管理员在 OMS 登记第三方认证系统的接入信息并启用
2. 用户在 OMS 登录页选择以第三方身份登录
3. OMS 引导用户前往第三方认证系统完成身份认证
4. 上游统一认证服务认证通过后，向 OMS 颁发 SSO ticket
5. OMS 校验该 ticket 的有效性与来源可信性
6. OMS 将外部身份与已导入的外部账号关联，并按会话策略建立 OMS 本地会话
7. 用户以映射后的本地身份进入 OMS

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 第三方认证系统未登记或已被禁用 | OMS 登录页不展示该外部认证入口 | 无 |
| 上游统一认证服务返回的信息范围 | 只提供身份信息，**不提供角色或权限信息**；OMS 不依赖上游返回的任何角色信息授权 | 无 |
| 外部账号的权限来源 | 以该账号在 OMS 导入时指定的用户组为准（见 FR-SSOC-003）；登录时不依据任何外部返回信息变更其用户组 | FR-SSOC-003 |
| 第三方返回的身份信息校验不通过 | 拒绝登录并提示认证失败 | 无 |
| 外部身份在 OMS 中无对应外部账号 | 拒绝登录并提示联系管理员预先导入；**不自动创建账号** | FR-SSOC-003 |
| 对应的本地账户已锁定或已停用 | 拒绝登录 | FR-ACC-004 |
| 第三方认证系统不可用 | 拒绝该方式登录，并允许用户改用其他已启用的登录方式 | 无 |
| 外部身份已绑定到其他本地账户 | 拒绝登录并提示身份冲突 | 无 |
| 通过外部认证建立会话 | 会话有效期、并发会话数与超时行为均按 OMS 会话策略执行 | FR-SEC-003 |
| 第三方认证系统被停用后用户已在会话中 | 已建立的本地会话不受影响，下次登录不再提供该入口 | 无 |

**待确认**

无

#### 3.2.2 FR-SSOC-002 级联登录与级联登出

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOC-002 | V1.0 |

**② 需求描述**

作为上层业务系统，我希望 OMS 作为 SSO 代理串联「下游业务系统 → OMS → 上游统一认证服务」的完整认证链路，以便用户在下游系统发起访问时一次完成认证，并在下游登出时使**整条链路以及所有使用该 ticket 免密登录的下游系统**的登录态同步失效。

**③ 前置条件与触发方式**

- 前置条件：下游业务系统已作为 SSO 客户端在 OMS 登记并启用；OMS 已作为 SSO 客户端在上游统一认证服务登记且可信关系有效；链路各段网络可达
- 触发方式：事件——用户访问下游业务系统的受保护资源且该用户未认证（级联登录）；事件——用户在下游业务系统登出（级联登出）

**④ 主流程**

1. 用户访问下游业务系统 A 的受保护资源，A 判定该用户未认证，将用户重定向到 OMS
2. OMS 判定自身没有该用户的本地会话，将用户重定向到上游统一认证服务 B
3. 用户在 B 完成凭据输入与身份认证
4. B 认证通过后向 OMS 颁发 SSO ticket
5. OMS 校验该 ticket，建立本地会话，并按外部角色映射确定该用户的用户组归属
6. OMS 向下游业务系统 A 颁发 ticket，A 校验后建立自身登录态并向用户放行受保护资源；OMS 记录该 ticket 已被哪些下游业务系统使用
7. 用户从任一使用过该 ticket 的下游业务系统登出时，该系统通知 OMS 使本次登录对应的 ticket 失效
8. OMS 撤销该 ticket，通知**所有曾用该 ticket 免密登录的下游业务系统**执行各自的登出逻辑，并随即通知上游统一认证服务 B 使其颁发的 ticket 失效

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 上游统一认证服务不可达 | 级联在 OMS 重定向环节终止，向下游返回认证不可用，不建立任何登录态 | FR-SSOC-001 |
| 上游颁发的 ticket 校验不通过 | 拒绝建立 OMS 本地会话，并向下游返回认证失败 | FR-SSOC-001 |
| 用户在 B 取消认证或认证失败 | 不建立 OMS 本地会话，下游保持未认证；用户可重新发起 | 无 |
| 下游业务系统未登记或已被禁用 | 拒绝本次请求，不为其颁发 ticket | FR-SSOS-001 |
| 下游业务系统不可达 | OMS 已建立的本地会话保持有效，下游保持未认证，用户可稍后重试 | 无 |
| OMS 本地会话已存在时下游发起级联登录 | 跳过重定向上游的环节，直接向下游颁发 ticket | FR-SSOS-001 |
| 用户从任一使用该 ticket 的下游系统登出 | OMS 撤销该 ticket，并通知**所有**曾用该 ticket 免密登录的下游业务系统执行各自的登出逻辑，而非仅通知发起登出的那一个 | FR-SSOS-002 |
| 部分下游系统在登出通知时不可达 | 记录未完成的下游系统并按策略重试；其登录态在超过会话有效期后自动失效 | FR-AUTH-003 |
| 用户从下游登出但 OMS 不可达 | 下游本地登录态立即失效；OMS 与上游的 ticket 在超过会话有效期后自动失效 | FR-AUTH-003 |
| OMS 使自身 ticket 失效时上游不可达 | OMS 本地 ticket 立即失效，并记录未完成的上游失效通知、按策略重试 | 无 |
| 上游统一认证服务被停用 | 级联不可用，OMS 本地登录方式不受影响 | FR-SSOC-001 |

#### 3.2.3 FR-SSOC-003 外部账号导入

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SSOC-003 | V1.0 |

**② 需求描述**

作为系统管理员，我希望按清单批量导入外部账号并指定其所属用户组，以便使用上游统一认证服务登录的用户在 OMS 侧预先具备用户组归属与相应权限，能够正常使用 OMS 的功能与资源。

**③ 前置条件与触发方式**

- 前置条件：操作者具备外部账号导入权限；待导入清单已准备且包含账号名、姓名与所属用户组；清单中指定的用户组已存在且可用
- 触发方式：页面入口——外部账号导入；事件——运维人员或上游统一认证服务提供外部账号清单

**④ 主流程**

1. 操作者进入外部账号导入入口，选择或获取待导入的账号清单
2. 系统解析清单，逐条按账号唯一性、用户组归属与三权分立互斥要求进行校验
3. 系统汇总校验结果，列出可导入账号与问题账号及原因
4. 操作者查看问题清单后确认导入
5. 系统为通过校验的账号建立**外部账号**记录（不在 OMS 侧保存认证凭据）并置为待激活，未通过的行不予导入
6. 系统反馈导入结果汇总，并保留导入过程留痕

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 导入产生的账号类型 | 一律为**外部账号**，不在 OMS 侧保存认证凭据；本地账号只能通过 M01 的创建账户产生 | FR-ACC-002 |
| 导入时指定的用户组 | 即该外部账号在 OMS 中权限的**唯一来源**；外部角色的映射在导入环节一次性完成，上游不参与角色映射 | FR-SSOC-001 |
| 需调整外部账号的权限 | 通过修改其用户组归属（FR-ACC-008）或重新导入实现，不存在运行时的角色映射 | FR-ACC-008 |
| 清单未指定所属用户组 | 该账号不予导入并列入问题清单；外部账号必须归属一个用户组才能获得权限 | FR-RG-002 |
| 清单指定的用户组不存在或已停用 | 该账号不予导入并列入问题清单 | FR-RG-002 |
| 清单中存在与既有账号重复的账号 | 该行不予导入并列入问题清单，不覆盖既有账号 | FR-ACC-002 |
| 导入数量超过账户策略规定上限 | 拒绝超出上限的部分并说明原因 | FR-SEC-001 |
| 导入账号经其用户组组合同时具备系统管理员与审计管理员能力 | 该账号不予导入并列入问题清单 | FR-ACC-001 |
| 上游统一认证服务尚未登记 | 允许先导入账号，但在完成登记前该账号无法登录 | FR-SSOC-001 |
| 导入后的账号状态 | 置为待激活，须由安全管理员激活后方可登录 | FR-ACC-005 |
| 部分账号校验未通过 | 通过校验的账号正常导入并保留，未通过的账号列入失败清单并逐条给出失败原因 | 无 |
| 导入失败账号的处理 | 系统不进行自动重试，由操作者修正清单后重新发起导入 | 无 |
| 导入过程中系统异常中断 | 已导入结果可追溯；系统不自动重试，由操作者修正清单后重新发起导入 | 无 |
| 操作者不具备导入权限 | 拒绝导入 | FR-PERM-001 |
| 导入完成 | 须留痕，并提供可追溯的导入结果 | FR-OPLOG-001 |

**待确认**

无
