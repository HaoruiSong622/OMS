## 1. 模块概述

第三方接入是 OMS 与外部基础设施对接的统一通道层，为告警上报、文件传输与证书签发等场景提供可配置、可管控的接入能力。它解决外部系统能力无法被 OMS 直接复用，以及接入关系分散在各模块导致难以统一管理的问题。本模块把接入关系集中登记、集中启停、集中查看运行状况，使运维与安全人员能够掌握 OMS 对外依赖的全貌。本模块不依赖其他 OMS 模块，但作为基础通道被告警管理、证书管理与备份恢复等模块使用。

| 项 | 内容 |
| --- | --- |
| 模块定位 | OMS 与外部基础设施之间的统一接入通道，提供 SNMP 告警上报通道、SFTP 文件传输通道（全局唯一连接）与 CA 证书签发对接三类能力 |
| 上游依赖 | 无，直接对接外部基础设施 |
| 下游影响 | M17 告警管理（通过本模块的 SNMP 通道对外上报告警）；M13 证书管理（**Nginx 对外证书**的 CA 签发与续约）；M10 备份恢复（SFTP 作为文件传输通道，用于备份数据包的同步上传） |
| 关键外部系统 | 上层网管系统（SNMP 上报目标）、SFTP 文件服务器、CA 服务器 |

### 3.1 FR-3RD-001 SNMP 告警上报接入

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-3RD-001 | V1.0 |

**② 需求描述**

作为系统管理员，我希望在 OMS 中统一配置并维护通过 SNMP 对接外部系统的上报通道，由 OMS 主动把告警等运维事件上报给外部系统，以便外部系统与 OMS 保持一致的运行视图，并使 OMS 的对外上报关系集中可见、集中管控。

**③ 前置条件与触发方式**

- 前置条件：外部系统已具备接收 OMS SNMP Trap 的条件且与 OMS 网络可达；SNMP 上报通道已配置并启用；上报目标与协议版本、认证信息已维护；上报内容与外部系统的映射约定已明确；上报方式固定为 **SNMP Trap**
- 触发方式：事件（OMS 产生告警、重复告警或告警消除且满足上报条件）；页面入口（接入通道的配置、启停、连通性测试与上报目标维护）；定时任务（通道可用性巡检与上报失败重试）

**④ 主流程**

1. 操作者在第三方接入页面新建 SNMP 上报通道，维护上报目标、协议版本与认证信息
2. 操作者发起连通性测试，系统向上报目标发送测试上报并返回测试结果
3. 操作者启用通道；通道处于停用状态时系统不对外发送任何 SNMP 上报
4. OMS 产生告警、重复告警或告警消除且满足上报条件时，系统按映射约定把上报内容转换为 **SNMP Trap** 并发送至上报目标
5. 系统记录每次上报的内容、发送结果与时间，供操作者查询；Trap 不要求对端回执，上报结果以「已发送」为准
6. 上报失败时系统按已配置策略重试，重试仍失败则产生接入异常告警并保留待上报内容
7. 系统按巡检周期检查通道可用性，发现不可用时产生告警并标记通道不可用
8. 上报目标或认证信息变更时由操作者更新，并重新测试连通性后方可继续上报

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 接入通道处于停用状态 | 不对外发送 SNMP 上报，记录被抑制的上报数量供运维查看 | 无 |
| 上报发送失败（上报目标不可达等） | 保留待上报内容并按策略重试；重试仍失败则产生接入异常告警 | 无 |
| 上报方式与配置归属 | 上报方式固定为 **SNMP Trap**，不使用需要确认送达的 Inform，也不依赖对端回执判定送达；协议版本、认证信息与上报内容映射均由操作者在通道配置中维护，每个通道独立生效 | 无 |
| 上报目标的地址或认证信息不正确 | 连通性测试失败并给出明确失败原因，不允许启用该通道 | 无 |
| 上报内容无法按映射约定转换 | 记录原始告警与失败原因并产生接入异常告警，不静默丢弃 | 无 |
| 短时间内产生大量告警 | 按通道执行限流与合并，关键级别告警不得被丢弃 | FR-ALM-001 |
| 外部系统的上报约定发生变更 | 由操作者更新映射配置，变更后重新测试并全程留痕 | 无 |
| 上报动作与结果 | 全程留痕，可供查询与审计 | 无 |
| 上报范围与上报时机 | 由 M17 告警管理按上报范围、级别与消除策略决定，本模块只负责按通道发送 | FR-ALM-004 |
| 通道或上报恢复正常（异常恢复） | 主动向 M17 告警管理上报消除信息，使接入异常告警消除 | FR-ALM-005 |

### 3.2 FR-3RD-002 SFTP 文件服务器接入

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-3RD-002 | V1.0 |

**② 需求描述**

作为业务运维人员，我希望在 OMS 中配置并维护**唯一一个**外部 SFTP 文件服务器的连接，以便备份文件投递等场景复用同一套连接而不必各自重复配置，也避免多连接带来的凭据维护与故障面扩大。

**③ 前置条件与触发方式**

- 前置条件：外部 SFTP 文件服务器已就绪且与 OMS 网络可达；操作者具备第三方接入配置权限；复用该连接的用途场景（如备份文件投递）已明确；OMS 侧尚未配置 SFTP 连接，或需先停用并删除现有连接
- 触发方式：页面入口（配置、修改、测试与启停该唯一连接）；定时任务（连接可用性巡检）

**④ 主流程**

1. 操作者进入 SFTP 接入配置页面，配置唯一的连接，填写服务器信息与访问凭据
2. 系统对凭据加密保存，并在页面上展示该连接的当前配置与状态
3. 操作者发起连通性测试，系统返回测试结果与失败原因
4. 操作者将连接启用，并确认其可服务的用途场景（如备份文件投递）
5. 需要传输文件的模块（M10 备份文件投递）统一复用该已启用的连接
6. 系统按巡检周期检查连接可用性，发现不可用时产生告警并标记
7. 连接信息或凭据变更时由操作者更新，并重新测试连通性后方可用于传输
8. 需更换文件服务器时，操作者先停用并删除现有连接，再配置新的唯一连接

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| OMS 全局仅允许一个 SFTP 连接 | 已存在连接时不再提供新建入口，拒绝创建第二条连接并提示当前连接信息 | 无 |
| 服务器信息或凭据不正确 | 连通性测试失败并给出明确失败原因，不允许启用该连接 | 无 |
| 访问凭据的保存与查看 | 凭据以加密方式保存，后续查看不回显明文 | 无 |
| 文件传输过程中连接中断 | 中止本次传输并产生告警，是否重试按对应用途场景的约定执行 | 无 |
| 巡检发现连接不可用 | 产生告警并将连接标记为不可用，相关用途场景暂停使用该连接 | 无 |
| 外部侧访问密码被改动 | 访问密码**默认不发生变更**，OMS 侧不要求定期轮换；一旦外部侧改动密码，定期连通性测试即失败并产生告警，由**系统管理员**在接入配置中更新凭据、重新连接并测试通过后方可恢复传输 | 无 |
| 连通性恢复通过（异常恢复） | 主动向 M17 告警管理上报消除信息，使连接不可用相关告警消除 | FR-ALM-005 |
| 备份文件投递等多个场景共用该连接 | 配置页面展示引用关系，连接故障时同时影响所有引用方 | FR-BAK-001 |
| 连接仍被用途场景引用时被删除 | 拒绝删除并提示当前引用方；确需更换时先停用再删除 | 无 |
| 外部服务器身份不可信 | 拒绝建立连接并提示原因，由操作者确认后再行处理 | FR-3RD-003 |

### 3.3 FR-3RD-003 CA 服务器接入

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-3RD-003 | V1.0 |

**② 需求描述**

作为安全管理员，我希望 OMS 对接**唯一一个**外部 CA 服务器以签发与续约证书，以便 OMS 对外的 **Nginx 证书**能够由统一权威机构签发并持续保持有效；本能力**不提供回退为自签证书的机制**，唯一 CA 不可用且证书临近到期时以告警提示运维处理。

**③ 前置条件与触发方式**

- 前置条件：外部 CA 服务器已就绪且与 OMS 网络可达；CA 侧已为 OMS 开通签发权限；证书用途与申请主体信息已明确；OMS 侧最多只接入一个 CA 服务器
- 触发方式：页面入口（发起申请、查看签发记录）；定时任务（证书到期前检查与自动续期）；事件（证书临近到期）

**④ 主流程**

1. 操作者发起证书申请，填写证书用途与主体信息
2. 系统将申请提交至该 CA 服务器
3. CA 完成签发后，系统获取证书并交由 M13 证书管理纳管与应用（含 Nginx 对外证书的替换）
4. 系统记录本次签发过程的关键信息，供审计管理员后续查询
5. 系统按证书有效期监控到期时间，临近到期时触发续期
6. 续期成功后更新证书并通知使用方；续期失败时产生告警并提示处理
7. 操作者可在签发记录中查询历史签发与续期情况

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 本能力的服务对象 | OMS 对外的 **Nginx 证书**；服务间通信证书采用部署期自签名生成，不经 CA 签发 | FR-CERT-003 |
| 待续约证书最初为自签名生成 | 同样可通过本能力续约为 CA 签发的证书，并完成对外证书替换 | FR-CERT-002 |
| CA 服务器不可用或无响应 | 终止本次签发并给出明确失败原因，不做静默失败 | 无 |
| CA 拒绝签发申请 | 展示 CA 给出的拒绝原因，提示操作者修正申请信息后重试 | 无 |
| CA 服务器数量 | **最多只接入一个**，申请时无需选择目标 CA，也不存在首选与备用 CA 的切换 | 无 |
| 唯一 CA 不可用且证书临近到期 | **不提供回退为自签证书的机制**；上报告警并在证书管理中标记为待处理，提示使用方提前处理 | FR-CERT-002 |
| 证书签发或续期成功 | 记录用途、主体、结果与时间，供审计管理员查询 | 无 |
| 申请的证书用途与该 CA 支持的证书类型不匹配 | 拒绝提交并提示该 CA 支持的证书类型 | 无 |

**待确认**

无
