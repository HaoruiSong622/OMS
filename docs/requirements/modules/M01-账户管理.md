## 1. 模块概述

账户管理是 OMS 的身份主体管理模块，负责账户从创建、变更到删除的全生命周期管理，是统一身份与权限体系的起点。账户分为两类：**本地账号**与**外部账号**。本地账号由 OMS 完成认证，创建时必须设置认证凭据；外部账号**不在 OMS 侧存储凭据**，认证由上游统一认证服务完成，且**只能通过 M05/M06 SSO 分册的外部账号导入产生，不能在本模块直接创建**。两类账号在状态管理、用户组归属、锁定、激活、删除与操作审计上使用同一套规则，差异仅在认证方式与凭据是否由 OMS 保存。本模块承载三权分立角色建模，要求系统管理员、安全管理员、审计管理员三个管理员角色相互制衡，从制度上避免权限过度集中。账户管理依赖安全策略管理提供的账户策略与密码策略，并依赖 M04 资源组与用户组管理提供可归属的用户组；**账户不直接持有角色，其能力与可访问资源范围全部经所属用户组传递**（见主文档第 5 章）。账户状态与用户组归属变化会直接影响登录认证是否放行、可访问范围如何收敛。账户的创建、变更、锁定、激活、重置与删除均属于敏感操作，必须全程可追溯、可审计。

| 项 | 内容 |
| --- | --- |
| 模块定位 | 统一管理 OMS 身份主体（账户）及其状态与用户组归属，区分本地账号与外部账号，支撑三权分立与账户全生命周期治理 |
| 上游依赖 | M15 安全策略管理提供账户策略与密码策略；M04 资源组与用户组管理提供用户组作为账户的归属对象（角色不直接绑定账户，见 M03） |
| 下游影响 | M02 登录管理依据账户状态决定是否允许认证；M08 操作日志管理接收账户变更留痕；M16 权限控制依据账户所属用户组生效访问范围 |
| 关键外部系统 | 上游统一认证服务（外部账号的认证由该服务完成；外部账号的导入能力归 M05/M06 SSO 分册） |

### 3.1 FR-ACC-001 三权分立角色建模

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-001 | V1.0 |

**② 需求描述**

作为系统管理员，我希望系统必须支持建立系统管理员、安全管理员、审计管理员三个相互制衡的管理员角色，且同一账户不得同时具备系统管理员与审计管理员的能力，以便满足职责分离与合规审计要求。

**③ 前置条件与触发方式**

- 前置条件：系统已完成初始部署；操作者承担系统管理员职责；角色管理能力已就绪，可提供服务
- 触发方式：账户管理页面的管理员角色建模入口；系统初始化事件

**④ 主流程**

1. 系统初始化时内置系统管理员、安全管理员、审计管理员三个管理员角色及其职责边界
2. 系统管理员进入管理员角色建模入口，查看三个角色的职责分工与相互制衡关系
3. 系统管理员按职责分离要求确认各管理员角色的能力范围与互斥要求
4. 系统在后续「角色与用户组绑定」时依据建模结果校验能力组合的合法性
5. 系统在角色绑定环节拒绝使同一账户同时具备系统管理员与审计管理员能力的绑定
6. 系统记录角色建模与调整过程，供审计追溯

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 同一账户经用户组组合后同时具备系统管理员与审计管理员能力 | 在角色绑定环节拒绝并说明违反三权分立要求 | 无 |
| 账户仅具备三个管理员角色中的一个 | 允许，符合职责分离要求 | 无 |
| 应急处置等特殊场景下请求临时合并管理员角色 | 拒绝，三权分立角色不允许任何形式的临时合并 | 无 |
| 三个管理员角色被删除或被禁用 | 拒绝，保证三权分立角色始终存在且可用 | 无 |
| 管理员角色的能力范围超出其职责 | 拒绝配置或要求系统管理员二次确认 | 无 |
| 非系统管理员发起管理员角色建模调整 | 拒绝操作 | FR-PERM-001 |
| 角色绑定请求引用的角色未内置或已停用 | 在角色绑定环节拒绝 | FR-ROLE-001 |
| 角色建模或调整完成 | 须留痕，保证变更可追溯 | FR-OPLOG-001 |
| 上层业务系统请求获得管理员角色 | 拒绝，管理员角色不对外开放 | 无 |

无

### 3.2 FR-ACC-002 创建账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-002 | V1.0 |

**② 需求描述**

作为系统管理员，我希望在 OMS 中创建本地账户并指定其所属用户组，以便被授权人员能够登录 OMS，并经由用户组获得对应的功能与数据权限。

**③ 前置条件与触发方式**

- 前置条件：操作者具备账户创建权限；账户策略与密码策略已配置；目标用户组已存在且可用
- 触发方式：账户管理页面的新建入口；账户导入

**④ 主流程**

1. 系统管理员进入新建账户入口，系统按当前账户策略与密码策略展示可归属的用户组与填写约束
2. 系统管理员填写账户基本资料、为账户设置初始凭据并指定该账户所属的一个用户组
3. 系统校验账户资料合规性、初始凭据是否满足密码策略以及用户组归属是否合法
4. 系统创建账户并置为待激活；初始凭据由系统管理员掌握并自行告知账户本人，系统不承担交付与通知
5. 账户本人首次登录成功后，该初始凭据立即失效，必须立即设置新凭据后方可使用系统
6. 新建账户出现在账户列表中，创建过程留痕

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 账户名与既有账户重复 | 拒绝创建并提示重复 | 无 |
| 初始凭据不满足密码策略 | 拒绝创建并指明不满足的策略项 | FR-SEC-002 |
| 初始凭据的来源 | 由管理员在创建账户时自行设置，系统不代为生成 | 无 |
| 账户本人首次登录成功 | 初始凭据立即失效，必须立即设置新凭据后方可使用系统 | FR-AUTH-006 |
| 初始凭据的线下交付 | 不在系统职责范围内，系统不提供送达与通知能力 | 无 |
| 账户数量达到账户策略规定的上限 | 拒绝创建并提示已达上限 | FR-SEC-001 |
| 所选用户组不存在或已停用 | 拒绝创建 | FR-RG-002 |
| 账户经所属用户组组合后同时具备系统管理员与审计管理员能力 | 拒绝创建 | FR-ACC-001 |
| 操作者不具备账户创建权限 | 拒绝创建 | FR-PERM-001 |
| 未指定所属用户组 | 拒绝创建；账户必须归属一个用户组才能获得权限 | FR-RG-002 |
| 指定多个用户组 | 拒绝创建；一个账户只能归属一个用户组 | FR-RG-003 |
| 本功能创建的账号类型 | 一律为**本地账号**，须设置认证凭据并由 OMS 完成认证 | 无 |
| 外部账号的创建 | 本功能不创建外部账号；外部账号只能通过 M05/M06 SSO 分册的外部账号导入产生 | FR-SSOC-003 |
| 账号类型的变更 | 账号创建后类型不可变更 | 无 |
| 账户创建成功 | 初始状态为待激活，须由安全管理员激活后方可登录 | FR-ACC-005 |
| 账户创建完成 | 须留痕，保证可追溯 | FR-OPLOG-001 |

**待确认**

无

### 3.3 FR-ACC-003 查看账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-003 | V1.0 |

**② 需求描述**

作为系统管理员，我希望按条件查询并查看账户的当前状态与职责信息，以便掌握账户全貌并核实账户配置是否正确。

**③ 前置条件与触发方式**

- 前置条件：操作者具备账户查看权限；账户已存在；操作者的数据可见范围已确定
- 触发方式：账户管理页面的账户列表与详情入口

**④ 主流程**

1. 操作者进入账户列表，系统按操作者的数据可见范围展示可查看的账户
2. 操作者按账户名、账户状态、所属用户组等条件筛选或检索账户
3. 系统返回匹配结果，并展示账户的**账号类型**、当前状态、所属用户组与相应的权限范围
4. 操作者进入账户详情，查看账户基本资料与最近一次登录等运行信息
5. 系统对敏感信息按脱敏要求展示
6. 系统返回查看结果，查看过程按策略留痕

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 检索条件无匹配结果 | 返回空结果并提示无匹配账户 | 无 |
| 操作者不具备账户查看权限 | 拒绝查看 | FR-PERM-001 |
| 请求查看超出数据可见范围的账户 | 仅返回授权范围内的账户，其余不可见 | FR-PERM-001 |
| 账号类型的展示 | 账户列表中区分并标注本地账号与外部账号 | 无 |
| 展示账户敏感信息 | 按脱敏要求展示，不呈现完整凭据 | NFR-SEC-006 |
| 查看已删除账户 | 不进入常规列表，仅在授权追溯场景下可查 | FR-ACC-007 |
| 审计管理员查看账户 | 允许只读查看，用于审计核实 | 无 |
| 账户查看行为 | 按策略留痕，保证查询可追溯 | FR-OPLOG-001 |

**待确认**

无

### 3.4 FR-ACC-004 锁定账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-004 | V1.0 |

**② 需求描述**

作为安全管理员，我希望对可疑账户一键执行锁定，以便立即阻断该账户的登录与使用，降低安全风险。

**③ 前置条件与触发方式**

- 前置条件：账户已存在且处于正常状态；操作者具备账户锁定权限
- 触发方式：账户管理页面的锁定入口；认证连续失败达到账户策略阈值时由登录侧触发的事件

**④ 主流程**

1. 操作者选择目标账户并发起锁定
2. 系统展示该账户当前状态并请求确认
3. 操作者确认锁定
4. 系统将账户置为锁定状态，一并终止该账户的在线会话
5. 系统记录锁定操作者与时间，并按策略通知相关责任人
6. 锁定完成后，该账户的登录请求被拒绝

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 账户已处于锁定状态 | 提示无需重复锁定，不重复处理 | 无 |
| 操作者尝试锁定自身账户 | 拒绝，避免自锁导致管理中断 | 无 |
| 锁定的账户是最后一个可用的管理员账户 | 拒绝锁定或要求安全管理员二次确认 | FR-ACC-001 |
| 对**外部账号（三方SSO认证账户）**执行锁定 | **拒绝锁定**；外部账号由上游统一认证服务完成认证、其生命周期归 SSO 分册管理，OMS 不提供对其的锁定能力，因而也不提供激活能力 | FR-SSOC-003 |
| 对**内置管理员账户**（系统管理员、安全管理员、审计管理员）执行锁定 | 拒绝锁定，保证三权分立能力持续可用 | FR-ACC-001 |
| 认证连续失败达到账户策略规定阈值 | 系统自动锁定该账户并按策略提示 | FR-SEC-001 |
| 已锁定账户发起登录 | 拒绝认证，不进入后续认证流程 | FR-AUTH-001 |
| 账户锁定动作 | 须留痕，记录操作者与时间 | FR-OPLOG-001 |
| 操作者不具备锁定权限 | 拒绝锁定 | FR-PERM-001 |

**待确认**

### 3.5 FR-ACC-005 激活账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-005 | V1.0 |

**② 需求描述**

作为安全管理员，我希望将系统管理员新建的待激活账户或已锁定的账户恢复为正常状态，以便账户在完成必要核验后能够正常登录使用，并与账户创建环节形成职责分离。

**③ 前置条件与触发方式**

- 前置条件：账户已存在且处于待激活或锁定状态；账户的创建信息（含所属用户组、初始凭据）已完整；操作者具备账户激活权限
- 触发方式：账户管理页面的激活入口

**④ 主流程**

1. 操作者选择目标账户并发起激活
2. 系统展示账户当前状态、锁定原因或待激活原因
3. 系统校验是否满足激活条件，如账户是否已指定所属用户组、策略要求的凭据是否已更新
4. 操作者确认激活，系统将账户状态置为正常
5. 系统按策略通知账户本人，并记录激活操作
6. 激活后的账户可正常参与登录认证

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 账户已处于正常状态 | 提示无需激活 | 无 |
| 待激活账户的创建信息不完整（如未指定所属用户组） | 拒绝激活并提示先补全账户信息 | FR-ACC-002 |
| 新账户的创建与激活 | 由系统管理员创建（含指定用户组）、安全管理员激活，两个环节由不同角色承担以形成职责分离 | FR-ACC-002 |
| 账户策略要求激活前必须重置凭据 | 引导先完成凭据重置，再允许激活 | FR-SEC-002 |
| 账户不存在或已被删除 | 拒绝激活 | FR-ACC-007 |
| 操作者不具备激活权限 | 拒绝激活 | FR-PERM-001 |
| 账户激活成功 | 解除登录限制，允许参与认证 | FR-AUTH-001 |
| 账户激活动作 | 须留痕，记录操作者与时间 | FR-OPLOG-001 |

**待确认**

无

### 3.6 FR-ACC-006 重置密码

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-006 | V1.0 |

**② 需求描述**

作为系统管理员，我希望为账户重置登录凭据，以便账户本人在遗忘或凭据失效后能够重新获得访问能力。

**③ 前置条件与触发方式**

- 前置条件：账户已存在且未被删除；操作者具备凭据重置权限；密码策略已配置
- 触发方式：账户管理页面的重置凭据入口

**④ 主流程**

1. 操作者选择目标账户并发起重置凭据
2. 系统校验操作者是否有权对该账户执行重置
3. 操作者按密码策略设置新凭据，或由系统按策略生成新凭据
4. 系统校验新凭据是否符合密码策略与历史凭据限制
5. 系统更新凭据，使该账户既有在线会话失效，并要求下次登录时修改凭据
6. 系统记录重置操作；新凭据的线下交付由操作者自行完成，不在系统职责范围内

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 对外部账号重置凭据 | 拒绝；外部账号不在 OMS 侧存储凭据，认证由上游统一认证服务完成 | FR-SSOC-003 |
| 新凭据不满足密码策略 | 拒绝重置并指明不满足的策略项 | FR-SEC-002 |
| 新凭据与近期使用过的历史凭据重复 | 拒绝重置，要求更换 | FR-SEC-002 |
| 操作者重置自身凭据 | 引导使用个人改密能力，不走管理员重置 | 无 |
| 重置审计管理员账户凭据 | 须满足三权分立约束，由具备职责的操作者执行 | FR-ACC-001 |
| 重置成功后既有在线会话 | 立即失效，需重新登录 | FR-AUTH-004 |
| 凭据重置成功 | 要求账户下次登录时必须修改凭据 | FR-AUTH-006 |
| 凭据重置动作 | 须留痕，且不记录凭据明文 | FR-OPLOG-001 |
| 新凭据的交付 | 不在系统职责范围内，系统不提供送达与通知能力，也不记录交付过程 | 无 |
| 操作者不具备重置权限 | 拒绝重置 | FR-PERM-001 |

**待确认**

### 3.7 FR-ACC-007 删除账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-007 | V1.0 |

**② 需求描述**

作为系统管理员，我希望对不再使用的账户执行删除，以便及时回收访问资格，同时保留历史操作记录用于审计追溯。

**③ 前置条件与触发方式**

- 前置条件：账户已存在；操作者具备账户删除权限；账户不承担唯一的管理员职责
- 触发方式：账户管理页面的删除入口

**④ 主流程**

1. 操作者选择目标账户并发起删除
2. 系统展示删除影响提示，说明账户将不可登录、历史操作记录仍保留
3. 操作者确认删除
4. 系统执行逻辑删除，账户退出常规账户列表，不再参与登录认证
5. 系统终止该账户的在线会话并解除其用户组归属
6. 系统保留该账户的历史操作记录与删除留痕，供审计追溯

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |

| 操作者删除自身账户 | 拒绝，避免管理中断 | 无 |
| 已删除账户发起登录 | 拒绝认证 | FR-AUTH-001 |
| 已删除账户的历史操作记录 | 完整保留，可追溯查询 | 无 |
| 删除方式 | 采用逻辑删除，不物理清除账户历史 | 无 |
| 新建账户使用已删除账户的账户名 | 允许，账户名可被重新使用 | 无 |
| 已删除账户的账户唯一标识 | 不复用，永久保留并仅用于历史记录追溯 | 无 |
| 重复删除同一账户 | 提示该账户已删除 | 无 |
| 账户删除动作 | 须留痕，记录操作者与时间 | FR-OPLOG-001 |
| 操作者不具备删除权限 | 拒绝删除 | FR-PERM-001 |

### 3.8 FR-ACC-008 修改账户

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-ACC-008 | V1.0 |

**② 需求描述**

作为系统管理员，我希望修改账户的基本资料与用户组归属，以便账户配置始终与人员岗位和授权要求保持一致。

**③ 前置条件与触发方式**

- 前置条件：账户已存在且未被删除；操作者具备账户修改权限；涉及的用户组已存在且可用
- 触发方式：账户管理页面的编辑入口

**④ 主流程**

1. 操作者选择目标账户进入编辑
2. 系统展示可修改项，包括基本资料与用户组归属
3. 操作者提交变更内容
4. 系统校验变更后的用户组归属与账户策略约束是否合法
5. 系统保存变更并同步更新该账户的权限生效范围
6. 系统向操作者反馈变更结果，并记录变更前后差异

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 变更后账户经其用户组绑定的角色同时具备系统管理员与审计管理员能力 | 拒绝修改 | FR-ACC-001 |
| 变更为另一个用户组 | 允许更换；同一时刻账户只能归属一个用户组，更换后原用户组的权限立即失效 | FR-RG-003 |
| 修改后的账户名与既有账户重复 | 拒绝修改并提示重复 | 无 |
| 拟归属的用户组不存在或已停用 | 拒绝修改 | FR-RG-002 |
| 变更导致账户权限范围缩小 | 立即生效，并收敛该账户在线会话的可用范围 | 无 |
| 账户处于锁定或待激活状态时的资料修改 | 仅允许不影响状态的资料修改，其余拒绝 | 无 |
| 用户组归属变更完成 | 同步至权限控制，确保访问范围与归属关系一致 | FR-PERM-004 |
| 操作者不具备账户修改权限 | 拒绝修改 | FR-PERM-001 |
| 账户修改动作 | 须留痕，可追溯变更内容 | FR-OPLOG-001 |
