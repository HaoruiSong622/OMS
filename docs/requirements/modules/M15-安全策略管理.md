## 1. 模块概述

安全策略管理集中定义 OMS 的账户策略、密码策略与会话策略，是平台安全基线在业务侧的统一定义入口。模块解决策略条款分散、口径不一致导致账户与登录行为难以统一约束的问题，把「账户怎么建、凭据怎么管、会话怎么控」沉淀为可配置、可追溯的统一规则。本模块不直接面向终端用户执行认证，而是作为规则来源向下游模块输出判定依据。上游不依赖其他模块；下游被 M01 账户管理（账户策略、密码策略）与 M02 登录管理（密码策略、会话策略）引用，策略调整将直接影响账户创建、凭据管理与登录会话行为。本模块不涉及外部系统对接。

| 项 | 内容 |
| --- | --- |
| 模块定位 | OMS 安全基线的统一配置中心，集中定义账户、密码、会话三类安全策略并向下游提供判定依据 |
| 上游依赖 | 无 |
| 下游影响 | M01 账户管理（依据账户策略、密码策略约束账户与凭据）；M02 登录管理（依据密码策略、会话策略约束认证与登录会话） |
| 关键外部系统 | 无 |

### 3.1 FR-SEC-001 配置账户策略

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SEC-001 | V1.0 |

**② 需求描述**

作为安全管理员，我希望集中配置账户策略，明确用户名规则（长度与字符集）、账户有效期与到期处理、长期未登录账户的处理要求，以及登录失败次数与锁定策略（锁定阈值、锁定时长、解锁方式），以便 M01 账户管理按统一规则约束账户，M02 登录管理按统一规则判定登录失败与锁定。

**③ 前置条件与触发方式**

- 前置条件：操作者具备安全策略配置权限，且仅安全管理员可修改；OMS 已完成初始化部署，账户策略已有初始取值；当前生效的策略取值可查看
- 触发方式：安全策略管理页面账户策略配置入口；策略变更事件

**④ 主流程**

1. 安全管理员进入账户策略配置页面，系统展示当前生效的账户策略取值及各项的合法取值范围
2. 安全管理员修改用户名规则（长度与字符集）、账户有效期与到期处理方式、长期未登录账户处理方式，以及登录失败次数与锁定策略（锁定阈值、锁定时长、解锁方式）
3. 系统校验各项取值是否在合法范围内、同一策略内各项取值是否相互冲突
4. 系统保存变更，并保留变更前后的取值与变更操作者，使策略调整可追溯
5. 系统按账户策略约定的生效时机使新策略生效，并在页面上明示当前取值的生效状态与生效时机
6. 策略生效后，M01 账户管理按新策略校验用户名与账户有效期，M02 登录管理按新策略累计登录失败次数并执行锁定与解锁判定

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 用户名长度或字符集规则超出允许范围 | 拒绝保存并提示该项的合法范围 | 无 |
| 账户有效期或到期处理方式未配置 | 拒绝保存，账户有效期与到期处理为必填策略项，且到期处理须明确账户到期后的可用性变化 | 无 |
| 长期未登录账户未指定处理方式 | 拒绝保存，须明确长期未登录的判定口径与处理方式（如提示、禁用或锁定） | 无 |
| 登录失败锁定阈值、锁定时长、解锁方式未配置完整 | 拒绝保存并提示缺失项，三者须成套配置 | 无 |
| 锁定时长或登录失败阈值超出允许范围，或所选解锁方式不可用 | 拒绝保存并提示合法取值 | 无 |
| 非安全管理员尝试修改账户策略 | 拒绝修改，仅安全管理员可修改安全策略 | 无 |
| 账户策略变更成功 | 记录本次变更留痕，包含变更时间、操作者、变更前后取值 | 无 |
| 账户策略变更后 | 按页面明示的生效时机执行：即时生效，或自下次登录（下次新建账户）起生效，不得出现生效时机不明 | 无 |

**待确认**

无

### 3.2 FR-SEC-002 配置密码策略

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SEC-002 | V1.0 |

**② 需求描述**

作为安全管理员，我希望集中配置密码策略，明确密码复杂度与最小长度、密码有效期与到期强制修改、历史密码不可复用、首次登录强制修改密码以及初始密码生成规则，以便 M01 账户管理与 M02 登录管理对凭据强度与凭据生命周期执行统一要求。

**③ 前置条件与触发方式**

- 前置条件：操作者具备安全策略配置权限，且仅安全管理员可修改；账户策略已配置，用户名规则可用于密码与用户名的相关性校验；当前生效的密码策略取值可查看
- 触发方式：安全策略管理页面密码策略配置入口；策略变更事件

**④ 主流程**

1. 安全管理员进入密码策略配置页面，系统展示当前生效的密码策略取值及各项的合法取值范围
2. 安全管理员修改密码复杂度要求与最小长度、密码有效期与到期强制修改要求、历史密码不可复用要求、首次登录强制修改密码要求，以及初始密码生成规则
3. 系统校验各项取值是否在合法范围内，以及初始密码生成规则与当前复杂度、最小长度要求是否一致
4. 系统保存变更，并保留变更前后的取值与变更操作者，使策略调整可追溯
5. 系统按密码策略约定的生效时机使新策略生效，并在页面上明示当前取值的生效状态与生效时机
6. 策略生效后，M01 账户管理按新策略生成或校验初始凭据并约束改密行为，M02 登录管理按新策略判定首次登录强制改密与密码到期强制修改

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 密码最小长度或复杂度要求低于允许下限 | 拒绝保存并提示该项的合法范围 | 无 |
| 密码有效期未配置或超出允许范围 | 拒绝保存，密码有效期须为必填策略项并明确到期后的强制修改要求 | 无 |
| 历史密码不可复用的次数超出允许范围 | 拒绝保存并提示合法取值，不得要求复用范围不可实现 | 无 |
| 首次登录强制修改密码要求未明确 | 拒绝保存，须明确是否强制修改及适用范围 | 无 |
| 初始密码生成规则不满足当前复杂度与最小长度要求 | 拒绝保存，生成规则须与复杂度要求保持一致 | 无 |
| 非安全管理员尝试修改密码策略 | 拒绝修改，仅安全管理员可修改安全策略 | 无 |
| 密码策略变更成功 | 记录本次变更留痕，包含变更时间、操作者、变更前后取值 | 无 |
| 密码策略变更后 | 按页面明示的生效时机执行：即时生效，或自下次改密（下次登录）起生效，不得出现生效时机不明 | 无 |

### 3.3 FR-SEC-003 配置会话策略

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-SEC-003 | V1.0 |

**② 需求描述**

作为安全管理员，我希望集中配置会话策略，明确会话超时时长、空闲超时、并发会话数上限、会话续期方式，以及**以会话数量为判定口径**的异地或多端登录限制，以便 M02 登录管理把登录会话的风险暴露时间与并发范围控制在可接受区间。

**③ 前置条件与触发方式**

- 前置条件：操作者具备安全策略配置权限，且仅安全管理员可修改；密码策略已配置，登录会话能够正常建立；当前生效的会话策略取值可查看
- 触发方式：安全策略管理页面会话策略配置入口；策略变更事件

**④ 主流程**

1. 安全管理员进入会话策略配置页面，系统展示当前生效的会话策略取值及各项的合法取值范围
2. 安全管理员修改会话超时时长、空闲超时、并发会话数上限、会话续期方式，以及异地或多端登录限制的允许会话数与处理要求
3. 系统校验各项取值是否在合法范围内，并校验空闲超时与会话超时之间的取值关系是否合理
4. 系统保存变更，并保留变更前后的取值与变更操作者，使策略调整可追溯
5. 系统按会话策略约定的生效时机使新策略生效，并在页面上明示当前取值的生效状态、生效时机，以及对既有会话是否适用
6. 策略生效后，M02 登录管理按新策略建立、续期、续用与终止登录会话，并对命中并发上限或异地、多端登录限制的登录请求**拒绝新登录**

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 会话超时时长未配置或超出允许范围 | 拒绝保存并提示该项的合法范围 | 无 |
| 空闲超时未配置，或空闲超时超过会话超时时长 | 拒绝保存，空闲超时不得超过会话超时时长 | 无 |
| 并发会话数上限超出允许范围 | 拒绝保存并提示合法取值 | 无 |
| 会话续期方式未明确 | 拒绝保存，须明确续期的触发条件与续期后的会话时长要求 | 无 |
| 异地或多端登录限制未明确 | 拒绝保存，须明确以**会话数量**为判定口径、允许的会话数上限，以及命中限制后拒绝新登录的处理要求 | 无 |
| 异地/多端登录的判定依据 | **按会话数量判定**，不依据 IP 地址或地域；**同一浏览器**开启多个窗口共享同一会话，计为**一个**会话；**不同浏览器或无痕模式**开启的窗口各自建立新会话，计为**独立**会话 | 无 |
| 非安全管理员尝试修改会话策略 | 拒绝修改，仅安全管理员可修改安全策略 | 无 |
| 会话策略变更成功 | 记录本次变更留痕，包含变更时间、操作者、变更前后取值 | 无 |
| 会话达到并发上限，或命中异地、多端登录限制 | **拒绝新登录**并向用户给出可理解的原因；既有会话保持可用，不被终止，也不得静默放行 | 无 |
