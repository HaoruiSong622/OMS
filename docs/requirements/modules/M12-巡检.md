## 1. 模块概述

巡检模块用于主动发现系统运行中的隐患，在被动作战响应之前把风险暴露出来。本期巡检范围仅包含证书巡检一项，即按配置周期对 OMS 在用证书执行检查，并对即将过期与已过期的证书分级提示。巡检结果可查询、可留痕，出现异常时交由告警管理模块通知相关人员。巡检对象来自证书管理模块，因此本模块的能力边界取决于证书数据的完整与准确。

| 项 | 内容 |
| --- | --- |
| 模块定位 | 按配置周期主动检查证书状态，发现即将过期与已过期的证书并分级提示 |
| 上游依赖 | M13 证书管理提供被巡检的证书及其有效期、适用对象等信息 |
| 下游影响 | M17 告警管理在巡检结果异常时产生告警，通知相关角色处置 |
| 关键外部系统 | 无 |

### 3.1 FR-INSP-001 证书巡检

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-INSP-001 | V1.0 |

**② 需求描述**

作为业务运维人员，我希望系统按配置周期自动对在用证书执行巡检并分级提示即将过期与已过期的证书，以便提前安排更换、避免证书失效导致业务访问中断。

**③ 前置条件与触发方式**

- 前置条件：操作者具备巡检相关权限；巡检周期已配置；M13 证书管理中已存在可巡检的证书
- 触发方式：定时任务（按配置周期自动执行）；巡检页面手动触发并查询巡检结果

**④ 主流程**

1. 操作者配置巡检周期与临近过期的分级提示口径
2. 系统按配置周期自动发起证书巡检
3. 系统逐一核对在用证书的有效期与到期状态
4. 系统按核对结果对证书分级标记为正常、即将过期或已过期
5. 系统留存本次巡检结果供后续查询
6. 巡检结果存在异常时，系统按告警管理要求产生告警并通知相关角色
7. 操作者进入巡检页面查询巡检结果与历史记录，对异常证书发起处置
8. 异常证书恢复后，系统主动向告警管理上报清除信息，使对应告警清除

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 巡检周期未配置 | 不执行自动巡检，并提示补充周期配置 | 无 |
| 巡检范围内无在用证书 | 本次巡检记为无异常并留存记录 | FR-CERT-001 |
| 证书有效期剩余不足阈值 | 标记为即将过期并按临近程度分级提示 | FR-CERT-001 |
| 证书已过期 | 标记为已过期，并按异常产生告警 | FR-CERT-001 |
| 巡检执行中途失败 | 记录失败情况，保留上一次有效巡检结果，供人工确认后重新巡检 | 无 |
| 巡检结果涉及新出现的异常 | 按告警管理要求产生告警并通知相关角色 | 无 |
| 异常证书完成替换或续约（异常恢复） | 主动向 M17 告警管理上报清除信息，使对应巡检告警清除 | FR-ALM-005 |
| 巡检结果查询与留痕 | 任意一次巡检的结果与执行情况均可查询，且不可被随意修改 | 无 |
| 操作者手动触发巡检时无相应权限 | 拒绝触发并提示无权限 | 无 |
