## 1. 模块概述

操作日志管理统一收集 OMS 各子模块以及上层业务系统产生的操作行为记录，为审计管理员提供可追溯、不可篡改的操作事实依据。模块解决操作行为分散在各子模块、事后追溯与合规检查时难以汇总查看的问题。上游依赖 M11 通用提供的子模块操作日志上报能力，下游影响审计合规工作。关键外部系统为上层业务系统，其操作日志可能一并纳入统一留存。日志保留期等数据保留要求统一遵循主文档《OMS-需求规格说明书.md》中的规定，本分册不重复定义。

| 项 | 内容 |
| --- | --- |
| 模块定位 | OMS 操作行为记录的统一接收、留存与查询出口 |
| 上游依赖 | M11 通用（子模块操作日志上报能力） |
| 下游影响 | 审计合规：为审计追溯与合规检查提供操作行为依据 |
| 关键外部系统 | 上层业务系统（可能上报其操作日志） |

### 3.1 FR-OPLOG-001 操作日志接收

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-OPLOG-001 | V1.0 |

**② 需求描述**

作为审计管理员，我希望系统统一接收各子模块与上层业务系统上报的操作日志并集中留存，以便在事后追溯时获得完整、可信的操作行为记录。

**③ 前置条件与触发方式**

- 前置条件：相关子模块已具备操作日志上报能力并已开启；上报来源（子模块或上层业务系统）已获准纳入统一留存；操作日志留存空间可用
- 触发方式：事件（子模块或上层业务系统发生操作行为并上报时自动处理）

**④ 主流程**

1. 子模块或上层业务系统在操作发生后上报操作日志
2. 系统确认上报来源是否已获准纳入统一留存
3. 系统确认日志具备必要信息：操作者、操作时间、操作对象、操作结果
4. 系统写入并留存该操作日志
5. 系统向上报方反馈接收结果；接收失败时按重试与告警要求处理

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 上报来源未获准纳入统一留存 | 拒绝接收，并记录该来源的异常上报情况 | 无 |
| 日志缺少操作者、操作时间、操作对象或操作结果 | 拒绝留存，并提示信息不完整 | 无 |
| 接收暂时失败 | 支持重试，避免日志丢失 | 无 |
| 重试后仍接收失败 | 产生告警并通知相关人员；后续接收恢复正常时主动向 M17 告警管理上报清除信息，使该告警清除 | FR-ALM-005 |
| 日志已写入留存 | 任何角色均不可修改、不可删除，无例外通道 | 无 |
| 同一操作被重复上报 | 按去重规则处理，避免同一操作重复留存 | 无 |
| 日志留存期限 | 遵循主文档关于数据保留的要求，不在本分册定义 | 无 |

**待确认**

无

### 3.2 FR-OPLOG-002 操作日志查询

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-OPLOG-002 | V1.0 |

**② 需求描述**

作为审计管理员，我希望按**时间范围、操作者、日志类型、操作结果与关键字**组合查询操作日志，以便快速定位与某项操作相关的事实记录。

**③ 前置条件与触发方式**

- 前置条件：操作日志已由各子模块或上层业务系统上报并留存；操作者具备操作日志查看权限
- 触发方式：页面入口（操作日志查询页面）

**④ 主流程**

1. 操作者进入操作日志查询页面
2. 操作者设置查询条件：时间范围、操作者、日志类型、操作结果、关键字（列表不展示「所属模块」，也不以其作为查询维度）
3. 系统按条件检索操作日志并分页展示
4. 操作者翻页浏览，或调整条件后重新查询
5. 操作者查看单条操作日志的详细内容

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 未设置任何查询条件 | **默认时间范围＝所有时间**：返回全部留存的操作日志，并在页面上提示当前为默认范围（不限时间） | OI-M08-003 |
| 日志类型的取值 | 只有**安全日志、操作日志**两个取值，不新增其它类型 | OI-M08-001 |
| 列表是否展示「所属模块」 | **不展示**：列表列固定为「操作名称 / 操作对象 / 用户 / 用户IP地址 / 日志类型 / 状态 / 发生时间」 | OI-M08-002 |
| 查询结果为空 | 明确提示无匹配记录，避免呈现为空白页 | 无 |
| 查询结果数量较大 | 分页展示，避免一次性返回全部结果 | 无 |
| 查询条件中的时间范围超出可查询范围 | 按实际可查询范围返回并给出提示 | 无 |
| 操作者无操作日志查看权限 | 拒绝查询 | FR-PERM-001 |
| 查看单条日志详情 | 展示内容与留存时一致，不可编辑 | FR-OPLOG-001 |

**待确认**

无

### 3.3 FR-OPLOG-003 操作日志导出 CSV

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-OPLOG-003 | V1.0 |

**② 需求描述**

作为审计管理员，我希望把查询命中的操作日志导出为 CSV 文件，以便离线分析或提交给外部合规检查。

**③ 前置条件与触发方式**

- 前置条件：操作者具备操作日志导出权限；查询条件已确定且可返回结果
- 触发方式：页面入口（操作日志查询页面的导出入口）

**④ 主流程**

1. 操作者在查询结果页面发起导出 CSV
2. 系统确认导出范围与当前查询条件一致
3. 数据量较小时，系统直接生成 CSV 文件供操作者获取
4. 数据量较大时，系统转为异步执行，完成后通知操作者
5. 操作者获取导出文件
6. 系统将本次导出行为记入操作日志

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 导出范围 | 与发起导出时的查询条件保持一致，不额外扩大或缩小 | 无 |
| 数据量较大 | 异步执行，执行期间不阻塞操作者的其他操作 | 无 |
| 异步导出完成 | 通知发起导出的操作者，并说明获取文件的方式 | 无 |
| 导出失败 | 给出失败原因，并允许重新发起 | 无 |
| 导出行为本身 | 记入操作日志，可被查询与追溯 | FR-OPLOG-001 |
| 导出内容 | 与查询所见记录一致，不含操作者不可见的数据 | FR-OPLOG-002 |
| 操作者无导出权限 | 拒绝导出 | FR-PERM-001 |

**待确认**

无

### 3.4 FR-OPLOG-004 操作日志国际化

**① 基本信息**

| 编号 | 目标版本 |
| --- | --- |
| FR-OPLOG-004 | V1.0 |

**② 需求描述**

作为审计管理员，我希望操作日志展示时按当前语言呈现操作类型等固定项，以便不同语言环境的人员都能读懂日志，同时保持日志原始数据唯一。

**③ 前置条件与触发方式**

- 前置条件：系统已配置可用语言；操作日志已留存且包含可多语言化的固定项
- 触发方式：事件（用户切换界面语言，或打开操作日志展示时）

**④ 主流程**

1. 操作者在当前语言环境下打开操作日志列表或单条日志详情
2. 系统按当前语言呈现操作类型等固定项的多语言文案
3. 操作者切换语言后重新查看同一条日志
4. 系统以切换后的语言重新呈现固定项
5. 日志原始记录保持唯一，不因语言切换新增或复制记录

**⑤ 异常与规则**

| 场景 / 规则 | 期望行为 | 规则来源 |
| --- | --- | --- |
| 当前语言下缺少对应文案 | 回退到系统默认语言呈现，并保持内容可读 | 无 |
| 用户切换语言 | 仅改变展示语言，不新增、不复制日志记录 | 无 |
| 日志中由用户自行填写的文字内容 | 保持原样呈现，不做自动翻译 | 无 |
| 同一条操作日志被不同语言用户查看 | 均指向同一份原始记录 | FR-OPLOG-001 |
| 导出 CSV 时的语言 | 按导出时操作者当前语言呈现固定项 | FR-OPLOG-003 |

**待确认**

无
