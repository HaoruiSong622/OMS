# OMS 设计原型

## 目录

```
design/
├── prototypes/
│   ├── login.html                 # 登录页（单文件，无外部依赖）
│   ├── app-shell.html             # 登录后的主界面外壳：侧边栏 + 顶栏 + 内容区
│   └── screenshots/               # 各状态截图
└── tools/
    ├── verify_login.py            # 登录页回归：54 项断言 + 自动出图
    ├── verify_shell.py            # 外壳 + 账户/会话/证书/备份/告警/组/日志/策略回归：732 项断言 + 自动出图
    ├── static_check.py            # 静态自检（不开浏览器）：脚本语法 / i18n 键一致与重复 / id 引用 / 标签闭合
    ├── check_fonts.py             # 检查中文实际用哪个字体渲染（防豆腐块）
    └── ascii_view.py              # 把渲染结果转成文本灰度图，便于无图形界面时判读版面
```

## 环境前提（重要）

**Linux/WSL 必须安装中文字体**，否则无头浏览器截图里的中文会全部变成豆腐块（□）。
Windows/macOS 自带中文字体，不受影响——所以会出现「同一个 HTML，你那边正常、我这边是方块」。

```bash
sudo apt-get install -y --no-install-recommends fonts-noto-cjk
fc-cache -f
fc-match "sans-serif:lang=zh-cn"     # 期望输出 Noto Sans CJK SC，而不是 DejaVu Sans
```

两个 HTML 的字体栈都已按 macOS(PingFang) / Windows(雅黑) / Linux(Noto Sans CJK、思源、文泉驿)
依次兜底，装了上面字体即可正常显示。

## 常用命令

```bash
# 回归并刷新 screenshots/（改完原型务必跑一遍）
python3 design/tools/verify_login.py
python3 design/tools/verify_shell.py

# 静态自检（秒级，不用起浏览器）：脚本语法 / i18n 键 / id 引用 / 标签闭合
python3 design/tools/static_check.py
python3 design/tools/static_check.py design/prototypes/login.html

# 中文渲染自检（传页面路径）
python3 design/tools/check_fonts.py design/prototypes/login.html
python3 design/tools/check_fonts.py design/prototypes/app-shell.html

# 文本灰度图：<状态> <页面>
python3 design/tools/ascii_view.py zh       design/prototypes/login.html
python3 design/tools/ascii_view.py captcha  design/prototypes/login.html
python3 design/tools/ascii_view.py settings design/prototypes/app-shell.html
```

脚本只用 Python 标准库 + 系统自带 Chromium/ChromeDriver，无需 pip 安装。
注意 Chrome 窗口外框比内容视口高 143px，脚本已做补偿；窄屏用 CDP 强制设备尺寸。

### 首次登录全流程（跨两个页面）

```
登录页  认证通过(初始口令)
  └→ 强制修改密码（新密码 / 确认密码）
       └→ 提示"请使用新密码重新登录" → 回到登录表单（初始口令已失效）
            └→ 用新密码登录成功
主界面  进入首页 → 弹出用户协议窗口（确定满 5 秒可点；取消则强制登出）
                 └→ 确认后正常使用系统
```

协议窗口**在主界面而非登录页**；未确认前窗口覆盖全屏，Esc 与点击背景均无法绕过。
跨页状态用 `sessionStorage`（`oms.pendingAgreement` / `oms.agreementConfirmed`）模拟服务端下发的"待确认"标记。

## 账户管理的两个角色视图

同一页面按当前登录角色切换（原型说明浮层可切换角色）：

| | 系统管理员（admin） | 安全管理员（secadmin） |
| --- | --- | --- |
| 可见菜单 | 全部（13 项 + 安全策略的权限另算） | **只有 安全策略 / 操作日志 / 账户管理 三栏** |
| 创建账户 / 导入账户 | 有 | **隐藏** |
| 勾选列 / 批量删除 | 有 | **整列隐藏**（该视图没有删除能力） |
| 操作列（本地普通账户） | 修改账户 / 重置密码 / 删除账户 | **只有 锁定 / 激活**（按状态二选一） |
| 操作列（内置账户） | 只有 修改账户 | **无操作按钮**（不允许锁定，含 secadmin 自身） |
| 操作列（三方SSO认证账户） | 重置密码置灰（FR-ACC-006） | **无操作按钮**（不允许锁定） |

> 安全管理员只能对**本地普通账户**执行锁定 / 激活：内置账户（admin / secadmin / secauditor）与
> 三方SSO认证账户都不提供该操作，操作列显示占位符 `—` 并带悬浮说明。

### 账户表的多选与批量删除（仅系统管理员）

- 每行行首一个勾选框；**内置账户（admin / secadmin / secauditor）的勾选框置灰不可选**
- 表头全选框只作用于当前筛选结果中的可选账户，支持半选（indeterminate）态
- 筛选栏顺序：`搜索 · 状态 · 认证类型 · 用户组 · [重置筛选]` …… `[批量删除（N）]`
  —— 重置按钮紧邻筛选选项（原先被推到行尾，容易误解为"重置表格"），改名为**重置筛选**
- 未选中任何账户时「批量删除」置灰；选中后按钮显示数量，页脚追加「已选 N 个」
- 批量删除走确认弹窗，列出待删账户名，并复用 FR-ACC-007 的影响提示

## 运行日志页（M09）

页头两个按钮 + 一张表格（5 列）：**文件名 · 收集时间段 · 状态 · 创建时间 · 操作**

- **收集日志** → 右侧抽屉，含「收集时间段」条目，两种模式：
  - **指定时间**：小时数输入，范围 **2-48 小时**（以当前时刻为终点向前推算）
  - **自定义时间**：用户指定起始 / 终止时间，校验起始早于终止
- **一键信息收集** → 确认窗口：「即将收集 ModelEngine 的系统状态、关键配置及 48 小时内的运行日志，请确认操作。」+ 确定 / 取消
- 状态三态：**成功**（绿）/ **失败**（红）/ **运行中**（蓝，呼吸点动画）；仅「成功」可下载，失败与运行中的「下载」置灰
- 「删除」走确认弹窗；文件名即打包后的压缩包文件名（`.zip`）

## 操作日志页（M08）

单张表格（无其他面板），7 列：**操作名称 · 操作对象 · 用户 · 用户IP地址 · 日志类型 · 状态 · 发生时间**。

- 筛选：关键字（操作名称 / 操作对象）、用户、日志类型、状态、时间范围（起止日期），一行内排布
- 状态用徽标区分**成功 / 失败**；日志类型徽标取值为**安全日志 / 操作日志**
- IP 地址与时间用等宽字体；时间格式 `yyyy-MM-dd HH:mm:ss`
- 按每页 10 条分页（13 条演示数据 → 2 页），页脚显示总条数与页码
- `导出 CSV`（FR-OPLOG-003）放在页头右侧，与账户管理页的按钮位置一致
- 无匹配记录时明确提示「无匹配记录」，不呈现空白页（FR-OPLOG-002 规则）

## 安全策略页（M15，仅安全管理员）

位于「设置」分组下的**首个条目**，**只有安全管理员可见**；系统管理员视角下「设置」仍是原来的 13 项
（看不到安全策略），直接访问 `#/security` 也会回落到首页。面包屑为「设置 / 安全策略」。
页面按「账户策略 / 密码策略 / 会话策略」三张卡片展示，共 20 项，每项 = **展示名 + 取值范围 + 默认值**：

| 分组 | 项数 | 内容 |
| --- | --- | --- |
| 账户策略 | 7 | 最大账户数 0-1024/50 · 最短账户名 1-32/1 · 最长账户名 1-64/32 · 失败锁定阈值 3-5/5 · 登录失败周期 3-30分钟/5 · 锁定时间 10-30分钟/10 · 允许同名用户 否 |
| 密码策略 | 11 | 最短 8-32/8 · 最长 8-32/32 · 必须含特殊字符 是 · 允许用户名/反向名 否 · 弱口令检查 是 · 机机账号重置/首登强制改密 否 · 与前N次不重复 0-5/5 · 永不过期 否 · 最长使用 30-999天/90 · 修改间隔 3-10分钟/5 · 到期警告 3-10天/7 |
| 会话策略 | 2 | 会话超时 5-120分钟/10 · 单账户会话上限 1-50/10 |

交互：数值越界 / 必填为空 / 最短长度大于最长长度 → 该项标红并给出提示，阻止保存；
「密码永不过期 = 是」时，密码最长使用时间与到期警告自动置灰；「恢复默认值」一键回退。

断言逐项核对了 20 项的展示名、取值范围与默认值，避免漏项或抄错。

### SNMP 接入的创建 / 修改抽屉

- 字段顺序：名称 · SNMP版本（SNMPv3 / SNMPv2c）· 是否进行连通性校验（开关）· IP地址（IPv4 或 IPv6）·
  端口（默认 **162**）· 安全用户名 · 鉴权算法（SHA-512 / SHA-384 / SHA-256 / SHA / MD5）·
  是否校验鉴权密码和数据加密密码的复杂度（开关）· 鉴权密码 + 确认鉴权密码 ·
  加密算法（AES-256 / AES-128 / DES）· 数据加密密码 + 确认数据加密密码 · 语言（中文 / 英语）·
  上报数据类型（当前只有「告警」，可勾可不勾）· 描述
- **SNMPv2c 自动隐藏认证与加密字段**（v2c 没有这些配置），切回 v3 再出现
- **创建后展示「引擎ID」**：创建时由系统生成（`0x80001F8880` + 12 位十六进制），列表以等宽字体展示（超长省略），
  修改抽屉里只读展示并说明「创建后不可修改」
- **连通性校验**：开关开启时保存即校验一次；校验不通过时**不允许启用**——配置照样保存，但通道强制置为
  **禁用**并提示原因（原型中 `192.0.2.1` / `198.51.100.1` / `2001:db8::1` 模拟不可达）
- **复杂度校验**：开关开启时按安全策略校验两个密码（≥8 位、≥3 类字符），关闭时不校验
- **凭据不回显**：修改时两个密码框为空，占位提示「不修改请留空」

- 卡片展示**引用方**（备份恢复 · 远程备份，使用中 / 未使用）：停用 SFTP 后，系统备份页的「远程备份」
  随之显示为关闭并说明「SFTP 接入已停用」（M10 与 M14 共用同一份 SFTP 配置）
