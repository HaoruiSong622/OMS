## 1. 设计概述

- 1.1 设计目标：把 SRS 的能力落成可实现的架构与模块，重点覆盖三权分立、默认拒绝、SSO 三重角色、任务中心、审计留痕
- 1.2 设计约束（来自 SRS，逐条列为**硬约束**）
  - 认证不可用时上层业务**拒绝登录、既有会话失效**，不得降级为免认证（OI-G-004）
  - 授权 = **能力维度（用户组→角色）× 范围维度（用户组→资源组）**，二者缺一即拒绝；账户→用户组→角色/资源组，**账户不直接持有角色或资源组**
  - 一个账户**只能归属一个用户组**；用户组可绑多角色、关联多资源组（并集）
  - 三权分立互斥（系统管理员 ∩ 审计管理员）**在角色绑定环节阻断**
  - 授权关系变更**即时生效**：受影响在线用户会话立即置过期，强制重新登录
  - 角色全部内置、权限范围运行时只读；架构须保留运行期自定义角色的扩展能力
  - 资源清单由上层业务注册查询接口、OMS 回调获取；**归属关系 OMS 侧只读**
  - 密码/凭据/密钥加密存储，明文不落日志；全链路加密，服务间通信证书由 M13 统一管理
  - OMS 自身功能**不因 License 未授权/过期/吊销而受限**（是否限制由上层决定）
  - **部署基线**：OMS 与 Nginx 以容器化方式部署在 Kubernetes 集群；数据库数据、运行日志与备份包落 **PVC**，应用配置落 **ConfigMap**，证书与密钥/凭据落 **Secret**
  - **扩展性要求**：当前不要求多实例，但应用须**无状态化**设计，保证后续可通过 HPA/多副本扩展（会话可外置、文件存储可抽象、定时与任务可选举/加锁）
- 1.3 设计原则：模块化单体/分层、无状态化 + 外部化状态、配置驱动、能力可插拔（上层业务模块注册区）、失败明确不降级、审计优先
- 1.4 设计范围与非范围：不含上层业务逻辑与业务数据；不含 SCC 内部算法实现；不含《接口/数据库/部署》文档的明细
- 1.5 关键设计决策（ADR）索引表：每条=问题 / 备选 / 结论 / 理由 / 影响章节（初稿见第 14 章）

## 6. 关键特性设计

> 每个特性统一按 **目标 → 需求来源(FR) → 设计要点 → 关键流程 → 异常与不降级规则 → 涉及数据/接口 → 图** 组织。

- 6.1 认证与登录（M01/M02/M15）
  - 本地账号认证、统一失败话术、连续失败计数与锁定、验证码触发阈值与生成校验
  - JWT 签发/解析/校验、签名密钥与轮换、时钟偏移容忍
  - 首次登录强制改密（改密后**既有会话全部失效**、需用新密码重新登录）、用户协议确认（账户+版本+确认时间，版本化与多语言，关联 OI-M02-005；主界面弹窗 5 秒倒计时后方可确认，取消即登出）—— **【FIG-SEQ-01 本地登录时序】**
  - 账户逻辑删除与 ID 不复用/名称可复用的并发处理；内置管理员账户不可锁、不可删的守卫
- 6.2 会话生命周期与在线用户（M02）
  - 空闲超时（无宽限期）、最大会话时长、续期判定、并发/多端登录**按会话数量判定、命中拒绝新登录**（既有会话不受影响）
  - 会话巡检任务、会话被剔除/账户被锁被删/授权变更时的失效广播
  - 在线会话查询与剔除的运行时口径；剔除仅终止本地会话、**不触发 SLO**
  - 并发点设计：连续失败计数与锁定、并发会话上限判定、续期与剔除/失效的并发控制
  - 失效触发源汇总表：登出、剔除、空闲超时、最大时长、账户被锁/停用/删除、改密、授权变更 —— **【FIG-SEQ-02 会话续期与失效时序】**
- 6.3 安全策略（M15）
  - 账户策略 7 项 / 密码策略 11 项 / 会话策略 2 项的配置模型、取值范围校验（含跨项约束：空闲超时 ≤ 会话超时、最短账户名/密码长度 ≤ 最长、生成规则须满足复杂度）、默认值、恢复默认
  - 策略生效与缓存刷新、跨模块策略变更事件（供 M01/M02 即时采用新口径）、变更前后取值留痕
  - 密码到期、密码历史与前 N 次不重复、弱口令检查的落地方式
- 6.4 SSO Server（M05）
  - SSO 客户端登记（客户端标识、密钥/凭据、重定向白名单、启用状态）
  - 单点登录：本地会话校验 → 建立客户端登录态；重定向地址校验与开放重定向防护
  - 单点登出：ticket 撤销 + **通知所有曾用该 ticket 免密登录的下游客户端**；不可达客户端标记待撤销并重试
  - 本地会话剔除**不触发** SLO 的边界；ticket 的签发与校验由本能力承担，**不依赖 M18 加解密模块** —— **【FIG-SEQ-03 单点登录】/【FIG-SEQ-04 单点登出（SLO）】**
- 6.5 SSO Client 与级联（M06）
  - 上游统一认证登记与协议适配（**协议待确认**）、ticket 校验与本地会话建立
  - 级联登录/级联登出链路、「下游→OMS→上游」的失败终止点、级联去重
  - 外部账号导入：清单解析、逐条校验（唯一性/用户组必填/三权分立互斥/上限）、部分成功语义、失败原因回执、留痕
  - 明确：上游只提供身份，**无运行时角色映射**；权限来源=导入时指定的用户组 —— **【FIG-SEQ-05 级联登录与登出】/【FIG-SEQ-06 外部账号导入】**
- 6.6 授权模型与权限点（M03/M04/M16）
  - 角色内置与版本化注册（初始化/升级时注册内置角色、权限点、菜单）
  - 用户组生命周期与成员管理（一账户一用户组；**迁入=解除原组+加入新组须原子完成**；内置组不可改名/删除、绑定角色固化）
  - 资源组与资源清单回调同步（上层注册查询接口 + OMS 回调；归属只读）
  - 权限点体系：接口权限点、菜单权限点、按钮权限点，与角色的映射表
  - 权限判定算法：能力并集 × 范围并集 × 有效期，默认拒绝 —— **【FIG-ACT-01 权限判定活动图】**
  - 权限拦截链在各层的落点（网关/接口/菜单/按钮/后台能力），缺层视为越权风险

  - 重复上报去重；日志类型仅**安全日志 / 操作日志**两类
  - 存储与不可篡改（写入后禁改禁删）、保留期与清理（OI-G-006 待定）
  - 查询/筛选（关键字、用户、类型、状态、时间范围）/分页/默认时间范围（未设条件＝全部时间）/CSV 导出（**大数据量转异步并通知**）、导出与下载留痕

- 6.9 运行日志收集（M09）

  - 备份产物：**加密 + 完整性校验**、先落本地（本地不可用即失败）；副本上限清理（最旧优先，手动/自动一视同仁）、外部 SFTP 副本不清理
  - 远程备份只读取自 M14 的全局唯一 SFTP；上传失败不影响本地成功（重试 + 告警 + 标「未同步」，恢复后报清除）；SFTP 失败对最终状态的判定与手动补传（OI-M10-003 待定）
  - **恢复仅提供后台脚本入口（无页面入口）**：包校验 → 二次确认 → 停服确认 → 恢复 → 结果核对 → 留痕；校验不通过标记不可用并禁止恢复
  - 与任务中心、告警的协同；备份/恢复结果上报 M08 —— **【FIG-SEQ-10 备份执行与远程同步】/【FIG-ACT-02 恢复流程】**

  - CSR 生成（RSA 2048/3072/4096、主题信息、常用名取访问地址）；**CSR 与私钥不留存、不保存未签发证书**
  - 过期预警开关与天数（30–90）、证书/CA 证书状态计算；**服务间通信证书在安装部署阶段自签名生成并颁发，无页面入口**
  - 巡检任务（周期与分级口径配置、手动触发）与分级提示、中途失败保留上一次有效结果、异常恢复→告警清除
  - CA 服务器续约入口（OI-M13-005 待定；本版按「生成 CSR → CA 签发 → 导入」两步走）—— **【FIG-SEQ-11 证书导入/覆盖与 CSR】/【FIG-SEQ-12 CA 签发/续期与证书巡检】**

  - 计量项通配：按文件声明解析、无内置清单；消耗由上层业务登记、解除即释放
  - 定时检查：后台配置（界面不可改）周期检查截止日期与消耗占比，产生告警与恢复清除；时间回拨防护

- 6.14 告警管理（M17）
  - 接收与校验、分级规则（可配、未覆盖按默认级别）、去重（同来源同内容且未清除即重复，**不设时间窗口**）、次数与最近时间累计
  - 屏蔽规则（来源/类型/关键字、生效时间段、原因必填、状态）与屏蔽标记语义（不展示、不上报、数据保留）；规则**到点自动生效/失效**
  - 清除：来源模块异常恢复上报（自动）/ 人工手动；清除后转历史，复现按新告警从零累计
  - 查询/筛选/排序/详情/统计（Top10 + 明细，按告警名称/ID 聚合、按需查询）/导出；告警记录不可删除
  - SNMP 上报委托 M14 通道（产生/重复/清除）
  - 缺失的枚举字典（告警ID、部件类型、级别取值）需在设计中补齐 —— **【FIG-CLS-02 告警模型类图】/【FIG-SEQ-13 告警接收-去重-上报-清除】**

  - 配置 → 连通性测试 → 启用；停用仅记抑制数不发送；失败重试与持续失败告警（恢复即清除）

  - 按通道限流与合并，关键级别不丢 —— **【FIG-SEQ-14 SNMP 上报与失败重试】**

  | License | **不迁移** | ESN 变化必须重新签发；旧授权信息存档备查 |
  | 证书 | 重新导入或重签 | 私钥迁移的安全要求；建议重新签发而非搬运私钥 |

- 11.12 迁移工具与执行方式：K8s Job 一次性迁移程序 / CSV+SQL 脚本、幂等与断点续跑、分批限速、迁移前后快照、迁移账本与对账
- 11.13 割接方案：切换顺序（停旧 → 导出 → 迁移 → 校验 → 切流 → 观察）、回退触发条件与步骤、双跑/并行验证期（可选）
- 11.14 迁移校验与验收：数量对账、抽样比对、**权限等价性验证**（旧权限在新模型下的可达性矩阵比对）、登录冒烟、审计留痕连续性
- 11.15 迁移期安全与合规：迁移数据脱敏与传输加密、迁移账号最小权限、迁移操作全程留痕、旧环境数据销毁
- 11.16 迁移风险与预案：数据量大导致的窗口不足、映射歧义、字段长度/编码差异、迁移中断续跑、回退演练 —— **【FIG-ACT-04 存量迁移与割接流程】**

- 12.10 存量迁移安全：迁移通道与落盘加密、迁移账号最小权限与时效、迁移数据脱敏、迁移完成后旧环境数据销毁与留痕
